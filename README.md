# Журнал BingX — Telegram Mini App

Собранная статическая страница приложения журнала BingX, раздаётся через GitHub Pages.

- Здесь только код и оформление страницы: данных о сделках, ключей BingX, токена бота здесь нет и быть не должно.
- Данные страница берёт у веб-приложения Google Apps Script трейдера; каждый запрос подписан Telegram (`initData`), без подписи — отказ.
- Исходники и план — в приватном репозитории журнала (`docs/plans/2026-09-30-miniapp-dashboard-plan.md`). Сюда файлы попадают только сборкой, руками не правятся.
